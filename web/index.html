Language specification & rationale

                        
Memory safety by removal,
not by runtime.

                        

                            C-- keeps the deterministic control flow and small runtime footprint of ISO C, and removes the
                            constructs behind entire classes of memory-corruption bugs at the grammar level.

module main;

fn factorial(n: int) -> int {
    if (n <= 1) { return 1; }
    return n * factorial(n - 1);
}

fn main() {
    let result = factorial(6);
    print(result);   // 720
}

                            01
                            
Eliminated hazards

                        

                        

                            Security analyses of major systems codebases consistently attribute ~70% of high-severity vulnerabilities to memory unsafety. C-- removes the underlying constructs outright:
                        

                        

                            

                                
Raw pointers

                                
No address-of (&), dereference (*), or pointer arithmetic exists in the grammar.

                            

                            

                                
Null references

                                
Absent by construction. Every binding requires a statically verified initial value.

                            

                            

                                
Unchecked indexing

                                
All collection accesses validate bounds at runtime with deterministic traps.

                            

                            

                                
Implicit coercions

                                
Strict static typing prevents silent narrowing, signed/unsigned mismatches, and truthy casts.

                            

                        

                    


                    

                        

                            02
                            
Design philosophy

                        

                        

                            Modern memory-safe languages typically trade simplicity for expressive alias tracking (borrow checking, lifetime annotations) or a garbage-collected runtime.
                        

                        

                            Where verification of arbitrary aliasing is complex, C-- enforces deep-copy value semantics and lexical immutability by default.
                        

                        

                            By treating composite collections (array, list, stack, queue) as isolated values on assignment and argument passing, C-- guarantees alias freedom without lifetime annotations.

Core guarantees

                    
Language architecture

                    

                        Six invariants enforced across the lexical, syntactic, semantic, and code generation phases. Each card links to a runnable example.
                    

                


                

                    

                        

                            01
                            CWE-119 · CWE-416 · CWE-476
                        

                        
Spatial & temporal memory safety

                        

                            Buffer overflows, null dereferences, and use-after-free are structurally unrepresentable. Allocation and reclamation for dynamic structures are managed by the runtime and emitted C99 helpers.
                        

                        
                    


                    

                        

                            02
                            Alias freedom
                        

                        
Deep-copy value semantics

                        

                            Containers behave like scalars. Binding a collection to a new name or passing it to a function performs a deep clone, preventing unintended mutation across call frames.
                        

                        
                    


                    

                        

                            03
                            Binding discipline
                        

                        
Immutability by default

                        

                            let bindings are immutable for their whole lexical scope. Reassignment is permitted only on bindings marked mut, and uninitialized declarations are rejected at parse time.
                        

                        
                    


                    

                        

                            04
                            Error recovery
                        

                        
Precision diagnostics

                        

                            60 structured diagnostic codes render source context, column-accurate carets, root-cause explanations, remediation hints, and edit-distance identifier suggestions.
                        

                        
                    


                    

                        

                            05
                            Execution targets
                        

                        
Dual-backend compilation

                        

                            Execute in the deterministic tree-walking reference interpreter (with step and call-depth guards), or transpile into self-contained, bounds-checked ISO C99.
                        

                        
                    


                    

                        

                            06
                            First-class containers
                        

                        
Intrinsic abstract data types

                        

                            Fixed-length array<T>, resizable list<T>, LIFO stack<T>, and FIFO queue<T> are generic types checked by the semantic analyzer.
                        

                        
                    

                

            

        


        
        

            

                

                    
Internal architecture

                    
Compilation & execution pipeline

                    

                        Four stages translate UTF-8 source into verified AST nodes, direct evaluation, or portable ISO C99.
                        Each stage can be inspected against the code currently in the playground.
                    

                


                
    
                    
  1. 
                        
    
                            Stage 01
                            cmm/lexer.py
                        
    
                        
    Lexical scanner
    
                        
    
                            Normalizes UTF-8 input and scans it into a deterministic stream of typed tokens with exact 1-indexed line and column spans.
                        
    
                        
    
                            Output → List[Token]
                            
                        
    
                    
    2. 

                    
  2. 
                        
    
                            Stage 02
                            cmm/parser.py
                        
    
                        
    Recursive descent parser
    
                        
    
                            Builds an Abstract Syntax Tree using LL(k) statement parsing combined with 10-tier Pratt precedence climbing for expressions.
                        
    
                        
    
                            Output → Program(AST)
                            
                        
    
                    
    3. 

                    
  3. 
                        
    
                            Stage 03
                            cmm/analyzer.py
                        
    
                        
    Semantic analyzer
    
                        
    
                            Resolves lexical scopes, checks type compatibility, enforces let/mut rules, and verifies return completeness.
                        
    
                        
    
                            Output → Verified AST
                            
                        
    
                    
    4. 

                    
  4. 
                        
    
                            Stage 04
                            interpreter · codegen
                        
    
                        
    Dual execution backends
    
                        
    
                            Target A — tree-walking reference evaluator.
    
                            Target B — hardened ISO C99 code generator.
                        
    
                        
    
                            Output → stdout · C99
                            
                                
                                
                            
                        
    
                    
    5. 
                


                

                    

                        

                            
Normative reference interpreter

                            

                                cmm/interpreter.py executes verified AST nodes with deterministic activation records, deep-copy value semantics, checked arithmetic, and a 100,000-step watchdog that stops runaway loops in interactive sessions.
                            

                        

                        

                            
ISO C99 source-to-source transpiler

                            

                                cmm/codegen_c.py lowers C-- into portable C99 for gcc -std=c99 -O2 or clang, injecting runtime bounds assertions, division-by-zero traps, and deep-copy helpers.
                            

                        

                    

                

            

        


        
        

            

                

                    
Grammar & idioms

                    
Language reference

                    

                        Canonical patterns for bindings, functions, containers, and structured control flow. Open any card in the playground to run it.
                    

                    

                        
                        
                    

                


                

                    

                        

                            
01. Bindings & scalar types

                            
                        

                        
let immut = 42;         // Immutable by default
mut counter = 0;        // Mutable binding
counter = counter + 1;  // Permitted reassignment

// Inferred scalar types: int, float, bool, string
let pi = 3.14159;
let active = true;
let name = "C--";

                    


                    

                        

                            
02. Functions & procedures

                            
                        

                        
// Typed function with explicit return type
fn add(a: int, b: int) -> int {
    return a + b;
}

// Void procedure (omits return type arrow)
fn greet(user: string) {
    print("Hello,");
    print(user);
    return;
}

                    


                    

                        

                            
03. Arrays & dynamic lists

                            
                        

                        
// Fixed-capacity array (bounds checked)
mut arr = [10, 20, 30];
arr[0] = 99;
print(arr.len());

// Dynamic list
mut items = list<string>();
items.push("alpha");
items.push("beta");
items.insert(1, "inserted");
print(items.pop());

                    


                    

                        

                            
04. LIFO stacks & FIFO queues

                            
                        

                        
// LIFO Stack
mut st = stack<int>();
st.push(10);
st.push(20);
print(st.peek()); // 20
print(st.pop());  // 20

// FIFO Queue
mut q = queue<int>();
q.enqueue(1);
print(q.dequeue()); // 1

                    


                    

                        

                            
05. Switch-case dispatch

                            
                        

                        
let day = 3;
switch (day) {
    case 1: { print("Monday"); }
    case 2: { print("Tuesday"); }
    case 3: { print("Wednesday"); }
    default: { print("Weekend"); }
}

// String literal matching (no break needed)
switch (cmd) {
    case "run": { execute(); }
    default: {}
}

                    


                    

                        

                            
06. Iteration & branching

                            
                        

                        
// Conditional branching
if (score >= 90) { print("A"); }
else if (score >= 80) { print("B"); }
else { print("C"); }

// Scoped C-style for loop
for (mut i = 0; i < 5; i = i + 1) {
    print(i);
}

// While & do-while loops
while (n > 0) { n = n - 1; }
do { n = n + 1; } while (n < 10);
