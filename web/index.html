LANGUAGE SPECIFICATION & RATIONALE

C-- (C Minus Minus)

An imperative systems programming language designed around Safety by Removal. C-- retains the deterministic control flow and minimal runtime footprint of ISO C while eliminating entire classes of memory-corruption vulnerabilities at the grammar level.

01

Eliminated Hazards

Empirical security analyses across major systems codebases consistently attribute ~70% of high-severity vulnerabilities to memory unsafety. C-- removes the underlying syntactic constructs outright:

Raw Pointers
No address-of (&), dereference (*), or pointer arithmetic operations exist in the grammar.
Null References
Absent by construction. Every variable binding requires a statically verified initial value.
Unchecked Indexing
All collection accesses validate bounds at runtime with deterministic traps on out-of-bounds indices.
Implicit Coercions
Strict static typing prevents silent narrowing conversions, signed/unsigned mismatches, and truthy casts.
02

Design Philosophy

Modern memory-safe languages typically trade language simplicity for expressive alias tracking (such as borrow checking and lifetime annotations) or heavy garbage collection runtimes.

"Where verification of arbitrary aliasing is complex, C-- enforces deep-copy value semantics and lexical immutability by default."

By treating composite collections (array, list, stack, queue) as isolated values on assignment and argument passing, C-- guarantees alias freedom without lifetime annotations.

CORE GUARANTEES

Language Architecture

Six foundational invariants enforced across the lexical, syntactic, semantic, and code generation phases.

01 CWE-119 / CWE-416 / CWE-476

Spatial & Temporal Memory Safety

Buffer overflows, null pointer dereferences, and use-after-free faults are structurally unrepresentable. Memory allocation and reclamation for dynamic structures are managed transparently by the runtime and emitted C99 helpers.

02 ALIAS FREEDOM

Deep-Copy Value Semantics

Composite containers behave identically to primitive scalars. Binding a collection to a new identifier or passing it to a function performs a deep structural clone, preventing unintended mutation across call frames.

03 BINDING DISCIPLINE

Immutability by Default

Declarations introduced with let are immutable throughout their lexical scope. Reassignment is permitted only on bindings explicitly marked with mut, and uninitialized declarations are rejected at parse time.

04 ERROR RECOVERY

Precision Diagnostics Engine

60 structured diagnostic codes render source context gutters, column-accurate carets, root-cause explanations, remediation hints, and Levenshtein edit-distance identifier suggestions.

05 EXECUTION TARGETS

Dual-Backend Compilation

Execute directly inside the deterministic tree-walking reference interpreter (with configurable step and call-depth guards) or transpile into self-contained, bounds-checked ISO C99 source code.

06 FIRST-CLASS CONTAINERS

Intrinsic Abstract Data Types

Fixed-length arrays (array<T>), resizable vectors (list<T>), LIFO stacks (stack<T>), and FIFO queues (queue<T>) are first-class generic types checked by the semantic analyzer.

INTERNAL ARCHITECTURE

Compilation & Execution Pipeline

A four-stage front-to-back architecture translating UTF-8 source text into verified AST nodes, direct evaluation, or portable ISO C99.

STAGE 01 cmm/lexer.py

Lexical Scanner

Normalizes UTF-8 input and scans source characters into a deterministic stream of typed tokens with exact 1-indexed line and column spans.

Output → List[Token]
STAGE 02 cmm/parser.py

Recursive Descent Parser

Builds an Abstract Syntax Tree using LL(k) statement parsing combined with 10-tier Pratt precedence climbing for expressions.

Output → Program(AST)
STAGE 03 cmm/analyzer.py

Semantic Analyzer

Resolves lexical scopes, checks type compatibility, enforces let/mut rules, and verifies control-flow return completeness.

Output → Verified AST
STAGE 04 interpreter / codegen_c

Dual Execution Backends

Target A: Tree-walking reference evaluator.
Target B: Hardened ISO C99 code generator.

Output → Stdout / C99

Normative Reference Interpreter

Implemented in cmm/interpreter.py, the reference evaluator directly executes verified AST nodes with deterministic activation records, deep-copy value semantics, checked arithmetic, and a 100,000-step execution watchdog to prevent runaway loops in interactive sessions.

ISO C99 Source-to-Source Transpiler

Implemented in cmm/codegen_c.py, the transpiler lowers C-- constructs into portable C99 suitable for gcc -std=c99 -O2 or clang, automatically injecting runtime bounds assertions, division-by-zero traps, and deep-copy helpers.

GRAMMAR & IDIOMS

Language Reference

Canonical syntax patterns for bindings, functions, native containers, and structured control flow. Click any snippet's action button to load it into the editor.

01. Bindings & Scalar Types

let immut = 42;         // Immutable by default
mut counter = 0;        // Mutable binding
counter = counter + 1;  // Permitted reassignment

// Inferred scalar types: int, float, bool, string
let pi = 3.14159;
let active = true;
let name = "C--";

02. Functions & Procedures

// Typed function with explicit return type
fn add(a: int, b: int) -> int {
    return a + b;
}

// Void procedure (omits return type arrow)
fn greet(user: string) {
    print("Hello,");
    print(user);
    return;
}

03. Arrays & Dynamic Lists

// Fixed-capacity array (bounds checked)
mut arr = [10, 20, 30];
arr[0] = 99;
print(arr.len());

// Dynamic list
mut items = list<string>();
items.push("alpha");
items.push("beta");
items.insert(1, "inserted");
print(items.pop());

04. LIFO Stacks & FIFO Queues

// LIFO Stack
mut st = stack<int>();
st.push(10);
st.push(20);
print(st.peek()); // 20
print(st.pop());  // 20

// FIFO Queue
mut q = queue<int>();
q.enqueue(1);
print(q.dequeue()); // 1

05. Switch-Case Dispatch

let day = 3;
switch (day) {
    case 1: { print("Monday"); }
    case 2: { print("Tuesday"); }
    case 3: { print("Wednesday"); }
    default: { print("Weekend"); }
}

// String literal matching (no break needed)
switch (cmd) {
    case "run": { execute(); }
    default: {}
}

06. Structured Iteration & Branching

// Conditional branching
if (score >= 90) { print("A"); }
else if (score >= 80) { print("B"); }
else { print("C"); }

// Scoped C-style for loop
for (mut i = 0; i < 5; i = i + 1) {
    print(i);
}

// While & Do-While loops
while (n > 0) { n = n - 1; }
do { n = n + 1; } while (n < 10);
