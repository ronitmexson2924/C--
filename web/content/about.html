Frequently asked questions

What is C--?

C-- (C Minus Minus) is a statically typed, memory-safe imperative programming language. It keeps C’s explicit, predictable style but removes raw pointers, null values, pointer arithmetic, and uninitialized variables, so the memory bugs that depend on them cannot be written.

How is C-- different from C?

C-- has no pointers or null, makes bindings immutable unless declared with mut, requires every variable to be initialized, checks every array and list index at runtime, and traps on integer overflow and division by zero instead of producing undefined behaviour. Collections are copied by value, so two names never alias the same data.

Is C-- memory safe?

Yes, by construction. Buffer overflows, null dereferences, and use-after-free are not expressible in the language, because the constructs they require do not exist in its grammar. Remaining runtime faults, such as an out-of-bounds index, stop the program with a clear diagnostic instead of corrupting memory.

Can C-- compile to C?

Yes. The C99 backend transpiles verified C-- programs into self-contained ISO C99 with bounds checks, overflow checks, and division-by-zero traps built in, ready for gcc -std=c99, Clang, or MSVC. You can try it with the Transpile C99 button in the playground.

Is C-- related to the C-- used by GHC?

No. The Glasgow Haskell Compiler uses an unrelated intermediate language that is also called C--. This C-- is a source language designed for people to write programs in.

What do I need to run C--?

Only Python 3.10 or newer; there are no other dependencies. Clone the repository and run python3 -m cmm run demo.cmm, or use the online playground without installing anything.
