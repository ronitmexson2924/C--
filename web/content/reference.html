01. Bindings & scalar types

C-- has four scalar types: 64-bit int, IEEE-754 float, bool, and UTF-8 string. Types are inferred from the initializer, every binding must be initialized, and only bindings declared with mut can be reassigned.

let immut = 42;         // Immutable by default
mut counter = 0;        // Mutable binding
counter = counter + 1;  // Permitted reassignment

// Inferred scalar types: int, float, bool, string
let pi = 3.14159;
let active = true;
let name = "C--";

02. Functions & procedures

Functions declare typed parameters and an explicit return type after ->. Procedures omit the arrow. The analyzer verifies that every path of a typed function returns a value of the right type.

// Typed function with explicit return type
fn add(a: int, b: int) -> int {
    return a + b;
}

// Void procedure (omits return type arrow)
fn greet(user: string) {
    print("Hello,");
    print(user);
    return;
}

03. Arrays & dynamic lists

Arrays have a fixed length and lists grow dynamically. Every index is bounds-checked at runtime, and assigning or passing a collection copies it, so two names never share the same data.

// Fixed-capacity array (bounds checked)
mut arr = [10, 20, 30];
arr[0] = 99;
print(arr.len());

// Dynamic list
mut items = list<string>();
items.push("alpha");
items.push("beta");
items.insert(1, "inserted");
print(items.pop());

04. LIFO stacks & FIFO queues

Stacks (last in, first out) and queues (first in, first out) are built-in generic types. Popping or dequeuing an empty container raises a clear runtime error instead of reading invalid memory.

// LIFO Stack
mut st = stack<int>();
st.push(10);
st.push(20);
print(st.peek()); // 20
print(st.pop());  // 20

// FIFO Queue
mut q = queue<int>();
q.enqueue(1);
print(q.dequeue()); // 1

05. Switch-case dispatch

switch matches integers or strings. Each case has its own block, there is no fall-through, and the analyzer rejects duplicate cases and mismatched types.

let day = 3;
switch (day) {
    case 1: { print("Monday"); }
    case 2: { print("Tuesday"); }
    case 3: { print("Wednesday"); }
    default: { print("Weekend"); }
}

// String literal matching (no break needed)
switch (cmd) {
    case "run": { execute(); }
    default: {}
}

06. Iteration & branching

Conditions must be bool and braces are mandatory. C-- supports if/else if/else, C-style for loops with a scoped counter, while, and do-while.

// Conditional branching
if (score >= 90) { print("A"); }
else if (score >= 80) { print("B"); }
else { print("C"); }

// Scoped C-style for loop
for (mut i = 0; i < 5; i = i + 1) {
    print(i);
}

// While & do-while loops
while (n > 0) { n = n - 1; }
do { n = n + 1; } while (n < 10);
